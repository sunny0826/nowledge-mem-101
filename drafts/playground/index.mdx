Save a memory and ask to recall it, or open **AI Now** to practise with the fictional Atlas planning example. In AI Now, ask for the Atlas planning context, import its sample interview file from **Library**, and return to the task to read the source, write an evidence brief, and save a checked result. Start a **New Task** to find that saved result again.

AI Now uses preset replies. **Research** shows a simulated no-evidence outcome; it does not perform web research. The guided versions of these exercises are available in the [AI Now course](/ai-now).

<Note>
Everything here runs locally in your browser with sample data. Nothing is sent anywhere, and refreshing the page resets the demo.
</Note>
