## 你将建立什么

完成课程后，一个真正关心的主题会拥有一套小而有效的知识系统：

```text
主题 → 长期记忆 → 来源 → 显式连接 → 知识变化 → 找回验证
```

课程使用 Atlas 团队的年度计划流程作为案例。可以换成自己的长期项目、客户、研究领域或工作方法。

## 开始前准备

- 完成 [Essentials 课程](/zh/essentials)。
- 在同一个 Space 中准备至少五条与真实主题有关的记忆。使用 Default 即可。
- 准备一份包含该主题来源资料的文档。
- 如果当前版本提供 Background Intelligence，并且希望课程中更新 Wiki 主题和知识变化关系，请配置 Remote LLM 并启用它。

<Note>
不要为了看起来更整齐而创建 Space。只有当两个真实场景持续互相干扰时，才需要离开 Default。
</Note>

## 这门课程不要求什么

不需要先设计完美的标签体系，不需要为每个主题建立文件夹，也不需要手动维护 Wiki。Mem 会在后台完成主题分组和图谱维护；需要负责的是选择有价值的来源、保持长期记忆清晰，并明确记录重要关系。
