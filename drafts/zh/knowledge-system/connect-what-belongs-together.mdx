搜索可以推断相似性。Nowledge Mem 中的 Memory Link 会记录一条已经确认有意义的关系，并说明为什么两条记忆应当一起读取。

## 轮到你了

<Steps>
  <Step title="选择一组真正相关的记忆">
    选择主题的核心决定，以及第 3 课中保存的来源结论。两条记忆必须位于同一个 Space。
  </Step>
  <Step title="在图谱中打开它们">
    打开 **Graph**，选择第一条 Memory 节点，再选择 **Connect memories**，然后选择第二条记忆。
  </Step>
  <Step title="说明关系">
    使用 `supports`、`challenges` 或 `depends_on` 等直接的关系名称。再写一条几个月后仍能理解的原因：

    ```text
    这份复盘支持进行试行，因为它记录了季度复盘总是过晚发现的依赖问题。
    ```
  </Step>
  <Step title="检查保存的边">
    选择两条 Memory 节点之间的连线，确认可以看到关系名称和原因。
  </Step>
</Steps>

## 你应该看到

<Check>
  图谱中出现连接两条记忆的线，关系内容说明了为什么它们应该一起读取。
</Check>

<Tip>
当许多记忆只属于同一个宽泛类别时，使用标签。只有当两条特定记忆需要因为某个原因一起读取时，才保存 Memory Link。
</Tip>

## 为什么这很重要？

显式关系比根据相似措辞做出的猜测更可靠。它能为未来的搜索和 AI 提供长期线索，说明一条记忆如何改变另一条记忆的含义。
