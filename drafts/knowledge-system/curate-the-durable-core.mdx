## Before you start

Use the topic audit and records from lesson 1. Search before creating anything new; the practice set already contains all three kinds of memory.

## Your turn

<Steps>
  <Step title="Choose three different jobs">
    Select three records that serve different purposes:

    | Kind | The question it answers | Atlas example |
    | --- | --- | --- |
    | `decision` | What was chosen, when, and why? | One annual review, starting with the September pilot |
    | `learning` | What happened, and what did it teach us? | A shared dependency was found after plans were committed |
    | `procedure` | What should someone do next time? | Collect plans, mark dependencies, assign owners, record preparation time |
  </Step>
  <Step title="Make each memory stand alone">
    Open each item in **Memories**. Replace vague references such as "we agreed" with the subject and decision. Preserve its date, source reference, and uncertainty. Keep the lesson 1 audit as a map to these records rather than merging them into one large note.
  </Step>
  <Step title="Set the type and importance">
    Check the memory's type against the purpose above. Mem can classify newly saved memories automatically; make the content's purpose clear. Review **Importance** in the memory details and give the central decision more weight than background context only if it matters more to future work.
  </Step>
  <Step title="Apply one shared label">
    Add `atlas-planning`, or an existing equivalent, to all three. In **Memories**, filter by that label and open each record to verify the result.
  </Step>
</Steps>

## What you should see

<Check>
  The label filter includes all three records. Each is understandable alone and answers its own question; other memories with the label may appear too.
</Check>

<Note>
If a newer decision changes an older one, do not rewrite history here. Lesson 5 shows how to preserve the change as a new memory.
</Note>

## Why this matters

Clear content helps a reader use each memory correctly. Types and labels provide context, while importance influences retrieval; it does not guarantee that a memory ranks first.
