Search can infer similarity. A Memory Link in Nowledge Mem records a relationship you have decided matters and explains why the two memories should be read together.

## Your turn

<Steps>
  <Step title="Choose a meaningful pair">
    Pick the central decision and the source-backed memory from Lesson 3. Both memories must be in the same Space.
  </Step>
  <Step title="Open them in the graph">
    Open **Graph**, select the first Memory node, then choose **Connect memories** and select the second memory.
  </Step>
  <Step title="Name the relationship">
    Use a plain relation such as `supports`, `challenges`, or `depends_on`. Add a reason that will still make sense months later:

    ```text
    The retrospective supports the pilot because it documents dependencies that quarterly reviews discovered too late.
    ```
  </Step>
  <Step title="Inspect the saved edge">
    Select the line between the two Memory nodes and confirm the relation name and reason are visible.
  </Step>
</Steps>

## What you should see

<Check>
  The graph shows a line between the two memories, and the edge explains why they belong together.
</Check>

<Tip>
Use a label when many memories share a broad category. Save a Memory Link only when two specific memories should be read together for a reason.
</Tip>

## Why this matters

An explicit relationship is stronger than a guess based on similar wording. It gives future searches and agents a durable clue about how one memory changes the meaning of another.
