## Before you start

Use the topic and core memories from lessons 1–2. Prepare one relevant source in the same Space. For the fictional Atlas topic, save this as `atlas-quarterly-retrospective.md`:

```markdown
# Atlas quarterly retrospective — fictional practice material

## Observation
During the August review, a shared dependency was discovered after two team
plans were committed. Resolving it required the teams to revise those plans.

## Proposed response
Compare longer-term plans across teams using the existing quarterly notes.
Record preparation time and any dependencies found before plans are committed.

## Evidence limits
This is one retrospective. No annual review has been tested yet, and no
reduction in missed dependencies has been measured.
```

## Your turn

<Steps>
  <Step title="Add the source">
    Open **Library** and import your document. Wait until it is **Searchable**, then open it and check that the expected text is present. A source can be used for questions before any memories are extracted.
  </Step>
  <Step title="Study it against the topic">
    Open the source and choose **Study with AI**. Ask one bounded question:

    ```text
    Compare this source with the Atlas annual review decision and planning learning. Show one relevant passage, explain what it supports and what remains untested, and propose at most one useful memory. If it only repeats an existing memory, say so instead of proposing a duplicate.
    ```
  </Step>
  <Step title="Check the proposed takeaway">
    Compare the proposal with **Observation** and **Evidence limits** in the practice source. It can support testing earlier coordination; it cannot show that annual reviews have already reduced missed dependencies.
  </Step>
  <Step title="Keep one verified takeaway">
    Select the checked proposal and use **Save 1** to keep it. If the takeaway is already in Mem, open that memory in **Memories** and add the verified source reference instead. Include the document name and section so the evidence can be found again:

    ```text
    Atlas dependency lesson — fictional practice

    The August quarterly review found a shared dependency after plans were committed. This supports testing earlier cross-team coordination, but does not establish the best review frequency or a measured benefit.
    Source: atlas-quarterly-retrospective.md, Observation and Evidence limits.
    ```

    Open the result in **Memories**. Check the source reference, apply `atlas-planning`, and ask in **Timeline** what this source establishes and what it leaves untested.
  </Step>
</Steps>

## What you should see

<Check>
  The complete source remains in Library. One new or improved memory carries the checked takeaway and a usable source reference, including the limits of the evidence.
</Check>

<Note>
**Study with AI** proposes knowledge. Nothing is written to long-term memory until you choose what to save.
</Note>

## Why this matters

The source preserves provenance and detail. The memory preserves the durable takeaway. Keeping both avoids turning a large document into either an opaque attachment or dozens of low-value fragments.
