The fictional Atlas case starts with a September decision to run one review per year, then follows an October decision to use two smaller reviews. Lessons 1 and 3 provide practice memories and a source. The dates describe that example history. Use your own records and dates when working on a real topic.

## Before you start

- Complete the [Essentials course](/essentials).
- Choose a topic with a few memories in one Space, or use the practice set in lesson 1. Default is fine.
- Prepare one relevant document, or use the sample retrospective in lesson 3.
- Configure a model for the AI reading and question-answering steps.
- Background Intelligence is optional for this course. Enable it if you want automatic Wiki grouping and EVOLVES detection; the exercises include checks you can complete without waiting for them.

<Note>
Keep the course records in the same Space so they can be retrieved and linked together. Use a separate Space when you need a distinct knowledge scope, not just another category label.
</Note>

## What this course does not ask you to do

Begin with a small set of records. Background processing can help organize them, while you check the sources, clarify decisions, and verify the meaning of links. The final test is whether a question returns the current answer with evidence and history.
