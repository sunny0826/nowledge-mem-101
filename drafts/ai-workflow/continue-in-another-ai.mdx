## Before you start

Have the work brief and the checkpoint from lesson 3 saved in Mem. Both AI tools must connect to the same Mem and have access to the Space containing those memories. Keep any longer draft referenced by the checkpoint accessible to the second tool.

## Your turn

<Steps>
  <Step title="Open a fresh session in your second connected AI">
    Choose a different AI tool connected to the same Mem. Do not copy the original work brief or the first tool's conversation into this session.
  </Step>
  <Step title="Ask it to recover the task state">
    Ask for retrieval before drafting:

    ```text
    Search Nowledge Mem for the Atlas landing page work brief and latest handoff checkpoint. Identify the memories you used. Summarize the goal, audience, constraints, current outline, confirmed decision, unresolved proof point, and next action. If either memory is missing, say so. Do not draft the copy yet.
    ```
  </Step>
  <Step title="Compare its context summary with the checkpoint">
    Check the summary against the saved memories. With the lesson 3 example, it should identify the operations-lead audience, the single "Try Atlas" call to action, and the missing verified evidence for section four.

    <Tip>
      If the tool cannot find the checkpoint, check that you can find it in Mem first. Then check the tool's connection and memory scope. **Context → Preview** shows the configured scope; the [connector guide](https://mem.nowledge.co/docs/integrations) covers setup. Ask for another search using the checkpoint's distinctive title.
    </Tip>
  </Step>
  <Step title="Draft and review the next part">
    Once the context is correct, send:

    ```text
    Using the brief and checkpoint you found, draft the hero and section four copy. Keep the agreed call to action. Mark missing customer quotes or metrics as "needs evidence". Do not invent them.
    ```

    Check the audience, wording, and evidence markers against the brief. Keep the draft for the final update in lesson 5.
  </Step>
</Steps>

## What you should see

<Check>
  The second AI identifies the saved brief and checkpoint, then produces the requested copy with the agreed call to action and unresolved evidence clearly marked.
</Check>

## Why this matters

Checking the retrieved context before drafting catches missing decisions early. The same saved brief and checkpoint can guide another tool without requiring it to have the first tool's chat history.
