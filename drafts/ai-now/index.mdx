## What you'll build

By the end of this course, you will have a decision-ready brief for one real question:

```text
Grounded question → Source material → Evidence brief → Research gaps → Saved result
```

The examples ask whether the Atlas team should add an annual planning review. Replace that question with one you genuinely need to answer.

## Before you start

- Complete the [Essentials course](/essentials).
- Configure a Remote LLM in **Settings → Remote LLM**.
- Save at least one relevant memory, such as a decision, plan, or customer insight.
- Have one source ready: attach a file to the task or use a document already in the Library.

<Note>
AI Now can search your memories and source material together. A useful answer still depends on the scope and evidence you give it.
</Note>

## What this course does not assume

You do not need every AI Now skill or a connected browser. The core path uses your memories, one source, and a clear question. Deep Research is optional when the answer needs current public information.
