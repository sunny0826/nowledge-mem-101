## Before you start

Continue the lesson 1 conversation with its checked context summary. Choose a source you can use with your configured AI provider.

## Your turn

<Steps>
  <Step title="Choose one primary source">
    Use interview notes, a retrospective, or another document directly relevant to the question. For the practice task, save the following as `atlas-planning-interviews.md` in a text editor:

    ```markdown
    # Atlas planning interviews — fictional practice material

    These notes are invented for this course, not real customer evidence.

    ## Interview A — dependency visibility
    A team noticed a shared dependency only after committing to its quarterly plan.
    The interviewee wants teams to compare longer-term plans before committing.

    ## Interview B — preparation burden
    Teams already write quarterly review notes.
    The interviewee would try a joint review if those notes could be reused,
    but does not want a second reporting process.

    ## Interview C — unanswered question
    No annual planning review has been tested by this team.
    These interviews contain no measurement of time saved or dependencies avoided.
    ```
  </Step>
  <Step title="Attach the file or use the Library">
    Drop the file into the conversation and send it with the instruction below. For a document already in **Library**, wait until it is **Searchable** and use its exact name in the prompt.
  </Step>
  <Step title="Tell AI Now how to use it">
    Continue the Atlas task with a specific instruction:

    ```text
    Read atlas-planning-interviews.md alongside the Atlas planning memories already found. First identify the document and its sections. Then list statements relevant to piloting an annual planning review, citing the interview heading for each. Separate what the notes say from your interpretation. Use only these sources; if you cannot read the file, say so.
    ```
  </Step>
  <Step title="Check one passage against the original">
    Open the file and compare a cited passage with the answer. In the practice material, Interview B allows a trial only if existing notes can be reused. It does not support adding more reporting.
  </Step>
</Steps>

## What you should see

<Check>
  AI Now identifies the correct document and sections. You can trace one finding to its passage, including the condition attached to it.
</Check>

<Note>
If attachments are unavailable, import the document through **Library** and refer to it by name after indexing. If AI Now cannot read it, resolve that first; a file name alone is not evidence that the contents were read.
</Note>

## Why this matters

A primary source gives the task evidence. It lets you distinguish what the material says from what you or the AI infer from it.
