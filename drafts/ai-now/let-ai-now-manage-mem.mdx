Since Nowledge Mem 0.10.95, AI Now can manage Mem itself in an ordinary task: explain how a feature works, check and change supported settings, and report a problem with diagnostics. Every change is read back and can be restored.

## What you'll accomplish

<Check>
You'll use one AI Now conversation to check a supported setting, change it, read back the saved value, review what changed, and restore the original value.
</Check>

## Learn with the simulation

On desktop, the simulation opens automatically when you enter this lesson. Follow the popup hints to ask about settings, change one, review the change, and restore it. If you close it, click **Start the simulation** under [Your turn](#your-turn) to reopen it. This lesson starts a fresh task with preset replies about one simulated setting; no model setup is needed.

<Note>
The simulation runs locally with preset replies. It does not call AI or search the web, and refreshing resets the practice. On mobile, read the steps first and use a desktop browser for the interactive exercise.
</Note>

## Before practising in the real app

- Nowledge Mem 0.10.95 or later.
- A model configured and tested in **Settings → Providers**, following [LLM Providers](https://mem.nowledge.co/docs/llm-providers). A model that supports tool calls is recommended. Remote and Cloud connections use the connected Mem server's model configuration.
- No separate entry or installed skill: ask in an ordinary AI Now task.

## What you should see

<Check>
The read-back value matches the setting you asked to change, the review lists only the changes actually made, and restoring returns the original value. A feedback submission, when you request one, returns a feedback number and states what was included.
</Check>

## Settings that need a restart

Some saved settings only apply after the backend restarts. AI Now can schedule a restart only when you explicitly request it, and only for a backend managed by the local desktop app; remote and Cloud connections cannot restart your local backend. After reconnecting, ask for the effective value again. Install or reinstall local models manually in **Settings → Models**.

## Ask about Mem and report problems

The same conversation can also cover help and diagnostics:

- Ask how to use Mem. AI Now consults current product documentation and explains the steps and how to verify the result:

  ```text
  How do I import Codex conversations into Mem? Use the current documentation to explain the first step and how to verify the import.
  ```

  Finding instructions does not prove that a connection works; complete any login or permission steps yourself.
- Investigate a problem with read-only checks first. Ask for confirmed facts, possible causes, and next steps to be separated:

  ```text
  Why did my AI Now task fail just now? Check available runtime state, configuration, and relevant diagnostics. Separate confirmed facts from possible causes and explain the next step.
  ```

  A diagnosis alone does not authorize a restart, deletion, configuration change, or feedback submission; request those actions explicitly.
- Submit feedback only when you ask for it. AI Now explains what it will send before submitting. Images are ones you select and attach to the conversation; there is no automatic screenshot. Bug reports normally include recent redacted logs, and you can request "no logs" or "no images". A successful submission returns a feedback number; if the result is unknown or times out, check for an existing report before sending again.

## Limits

- **Auto** skips confirmation prompts but does not grant account permissions or enable unsupported backend operations. Scheduled tasks do not inherit chat auto-approval.
- Hosted Cloud does not provide local files, Shell, Browse Now, or local app plugins, and its feedback content differs from local and self-hosted connections. Web and mobile clients work through the connected Mem server.
- The supported settings depend on your connection and version. Ask AI Now to check what your connection supports instead of assuming a fixed list.

## Why this matters

You can resolve configuration questions where they appear, without leaving the task at hand. Because every change is read back and can be listed and restored, you stay in control of what was modified.
