## Learn with the simulation

On a desktop browser, go to [Your turn](#your-turn) and click **Start the simulation**. Follow the popup hints to send a request, read its reply, and check the result. Each lesson prepares its fictional Atlas materials; no model setup is needed.

<Note>
The simulation runs locally with preset replies. It does not call AI or search the web, and refreshing resets the practice. On mobile, read the steps first and use a desktop browser for the interactive exercise.
</Note>

## What you should see

<Check>
  The source is Searchable in Library, and AI Now identifies the correct document and sections. You can trace one finding to its passage, including the condition attached to it.
</Check>

<Note>
You can also attach a file directly to an AI Now conversation for analysis. This course uses **Library** so a fresh task can find the original later. A file name in a saved memory does not prove that the original can be reopened. If AI Now cannot read it, check the document's Space and indexing status before continuing.
</Note>

## Why this matters

A primary source gives the task evidence. It lets you distinguish what the material says from what you or the AI infer from it.
