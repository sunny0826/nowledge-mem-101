Before two AI tools can continue the same work, they need a shared starting point. Create a short, self-contained brief with the task, its constraints, and the next decision.

<Check>

## Why this matters

A work brief is not a transcript. It keeps only the durable context a new session needs to start within the right boundaries. It should make sense without the conversation that created it.
