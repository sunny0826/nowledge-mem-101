The task brief is ready. Now use the first connected AI to make a useful first pass.

## What you'll accomplish

<Check>
  You'll have one AI tool use the work brief in Mem to produce a first draft or make a decision.
</Check>

## Your turn

<Steps>
  <Step title="Open a fresh session in your first connected AI">
    Use the AI tool you want to start with. Do not paste the full work brief into the session.
  </Step>
  <Step title="Tell it what to find and create">
    Give the task a distinctive name and ask the tool to check its context before working:

    ```text
    Read the Atlas landing page work brief in Nowledge Mem. First list the goal and constraints you found. Then draft a six-section page outline that follows them.
    ```
  </Step>
  <Step title="Check the first pass against the brief">
    Confirm that the outline addresses the operations-lead audience, uses plain language, and includes one clear call to action.

    <Tip>
      If the tool misses a constraint, point it back to the brief. If the brief itself is incomplete, correct it in Mem.
    </Tip>
  </Step>
</Steps>

## What you should see

<Check>
  The AI states the relevant context before drafting, then produces a first pass that follows the saved constraints.
</Check>

## Why this matters

This works because the tool can read context you chose to preserve, not because it remembers a private chat. That is what lets the work move between tools.
